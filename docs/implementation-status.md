# Implementation status — 2026-10-23

The [revised life-simulation architecture](life-simulation-architecture.md) is the current proposed direction: a human player with a separate Chog pet, NFT-bound household economics, modular anime graphics, editable homes and deeper place/social simulation. It includes an audit of the gaps in this build, including fixed furniture, repeated city layouts and the source-Tier/computed-rank mismatch. The items below describe the existing implementation; the proposed replacement systems are not implemented yet.

The original indoor slice has been expanded with the user's Chog reference, the complete original NFT source, player identity settings and physical neighborhoods.

## Implemented

- **Source collection:** all 1,969 mainnet tokens, exact shuffled URI mappings, original metadata/image references, 13 trait categories, complete rarity scoring, faucet proofs and onchain starter-estate rarity proofs. Fixed snapshot block 115722652. Every metadata hash and proof reproduces locally. See [source provenance](chog-source.md).
- **Residents:** original NFT portraits and raw traits; corrected Skin/Body/Eyes/Accessory semantics; bounded stats derived from original traits. The supplied purple spiky Chog now replaces the green generic preview. Original token 1 has a separate six-state pink/jersey/BTC-glasses/Fwog rendering. Other NFTs retain distinct trait-based interpretations and authentic portraits. The collection browser filters real traits and can preview individual NFTs without claiming ownership.
- **Player identity:** editable name, sex/gender, self-described gender and optional pronouns, saved locally or through the signed shared service. These do not change appearance, rarity, starting money or stats.
- **Five cities:** Monhattan / Monad, Gwei York / Ethereum, Basedford / Base, Arbiquerque / Arbitrum, Polygone-on-Sea / Polygon. Each has distinct infrastructure names and architecture palettes, café, workplace, gardens and station. All five use live mainnet EVM gas. Sanctuary is a non-city recovery space.
- **Physical movement:** rendered homes and streets, solid building/furniture footprints, timed sidewalk routes, object dialogs, approach before city service activities, home entry/exit, guest-home proximity/privacy checks, depth sorting and seated/sleeping/eating poses. An unwalkable destination cannot start a journey.
- **Life/economy:** one serialized reducer for time, bounded offline settlement, food/rest/social needs, jobs, exact-wei gas predictions, XP, quests and upgrades. Meals, fares, improvements, land and upkeep use the per-chain gCHOG gas index; free recovery remains available.
- **Homes and shared property:** rarity-based starter parcel counts and housing tier, interior palette, visitor access, open-home visits, adjacent land purchases, funded player offers, atomic acceptance/payment/parcel transfer, cancellation/rejection refunds, protected home roots and connected estates. Parcels and escrow follow the NFT identity through wallet transfers.
- **Shared social:** public resident/home profiles, online presence and proximity-gated wave/chat/high-five interactions with cooldowns and bounded social gains. Other residents' balances, sessions and jobs are not exposed.
- **Authority:** Neon state, wallet login challenges/cookies, current NFT ownership checks, server time/quotes, revision conflicts and idempotent command receipts. New property operations serialize across both parties in PostgreSQL. Browser saves are never imported into shared economics.
- **Contracts:** tested unofficial NFT faucet, transfer-aware paginated V2 registry and `ChainWorldLand` with rarity-proof starter parcels, signed/limited/expiring prices, ERC20 offer escrow, ownership transfer, replay guards, refunds and estate connectivity. The source-mapped NFT faucet (`0x9fcC2FB7487A3530809f45DFD9bb419EA2E0aF17`) and linked V2 registry (`0xA4aB8dbc0b3213C2d80af677bD7B4b5f259BdD0f`) are deployed and configured on Monad Testnet. The separate land contract remains undeployed. [Public deployment record](../data/deployments/faucet-monad-testnet.json).
- **Faucet onboarding:** free lifetime claim per wallet with player-paid test MON gas, original-art preview, fresh supply/proof simulation, account-scoped pending receipt recovery, replacement/revert handling, minted-token selection including zero, and verified local metadata for reliable game entry. Deployment tooling verifies source/network/contracts and atomically configures browser/server addresses; local-key deployment resumes from a private transaction journal.
