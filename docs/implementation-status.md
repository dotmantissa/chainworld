# Implementation status — 2026-10-24

The current build includes the care, pantry/skills, saved-queue, NPC-goal and room-detection additions committed after the production demo. The wallet-only release publishes these additions and the subsequent [playability pass](playability-audit.md) together.

The browser build now implements the first playable household/city stages of the [life-simulation architecture](life-simulation-architecture.md). The human player and Chog pet are separate. Saved geometry controls the room, furniture and navigation; the world combines original rendered furniture/materials with an articulated human mesh. The complete architecture remains a longer-term specification, with the limits below still open.

## Implemented

- **Chog workshop economy:** paid materials become actual goods through physical coding, sketching and cooking actions; city businesses consume stock for once-per-day NFT orders. Traits determine a price specialty, care/bond improve real job earnings, and three paid workshop levels improve commissions and supplies. Materials, goods, upgrades and daily receipts remain NFT-household state. See [rules and authority](chog-workshop.md).
- **Finished resident mesh pass:** continuous authored body/face topology, four hairstyles, casual garment surfaces and shoes replace the primitive body. The same NFT-seeded, weighted character renders in homes, streets, NPCs, visitors and portraits. All skeletal actions, CPU fallback and shower blur remain supported. [CC0 source and compiled asset provenance](character-art.md).
- **Wallet-only signup and stable scene handoffs:** connect a wallet, switch to Monad Testnet, claim/verify a Test Chog and sign in. Returning owners reuse valid sessions and load current server state through one loading screen. Anonymous/source previews, browser-only progression and the shared-world build flag are removed; the collection is read-only. Old preview saves cannot enter the economy. Session/ownership rejection returns to sign-in, while transient metadata refresh retains valid play. Doorway scenes commit after confirmation, eliminating the reproduced home/street/venue reversal under late movement acknowledgments. Routine saving and walking stay responsive.
- **Direct building and skeletal action animation:** edit furniture directly in the rendered home, with engine-enforced Build mode, owned drag/drop, green/red validation ghosts, atomic placement, rotation, storage, resale and world wall/door tools. A weighted 26-bone human mesh covers all actions, walking/idle, jobs, pet care, NPCs and visitors, with a CPU fallback. Bathing scrubs, blurs the resident and adds frosted glass, water and drifting vapor. See [implementation](direct-building-and-animation.md).
- **Public interiors and essential care:** all five cities have libraries and librarians; public cafés, workplaces, libraries and parks use authored 12×12 plans with at least 20 appropriate furnishings and clear aisles. New homes include an essential shower, with a one-time safe legacy migration and preserved budgets. Six original commercial assets and a library exterior have recorded provenance.

- **Background saving:** command projection and authoritative synchronization are separate. User input remains active during slow writes; unsent movement coalesces, stable IDs survive ambiguous-response retry, conflicts rebase, rejected purchases roll back, and session outboxes support reload recovery. The session command journal batches into idle work. Direct controls avoid unrelated gas/registry RPCs, and neighborhood polling no longer resets each projected tick. Both ownership checks and atomic server authority remain intact. See [background saving](background-saving.md).
- **Realism and care pacing:** six original transparent 3D-rendered furniture assets (bed, kitchen, sofa, desk, basin, shower); grounded lot/foundation/contact shading, wet-area tile, correct cutaway partitions/door frames, front-facing object approach, duvet/glass layers and physical water/steam/food effects. Basin and 2×2 shower are purchasable functional objects. Basic care is faster; existing active timers survive reload unchanged. See [direction and current animation limits](realism-direction.md).

- **Playability / interface:** the default screen is the world, six actionable needs, one prioritized suggestion and three tool buttons. Resident editing, pet care, pantry, rewards, building, travel and neighbor details open deliberately. NFT selection is available when needed; character settings are optional inside the game. Object choices are compact; kitchens link to supplies and desks to advanced work. The liquidity job now approaches an actual desk instead of submitting an invalid generic indoor action.
- **Movement / feedback:** ordinary walks can be redirected from a legal tile; WASD walking and E interaction work on the focused world. Current-segment facing, route dots/destination rings, object hover labels/highlights, gait/idle/use effects, action countdowns and interpolated outdoor pet following improve feedback. Human motion now uses the weighted skeletal renderer; roaming NPC schedules remain future work.

- **Room detection:** partitions and door edges derive architectural rooms independently of walkable routes. Build & Buy shows each room’s area, clear cells, furnishings and connecting doors; the actual room shows editable tile/edge overlays and an optional room summary. New structural edits cannot cut through furniture, while older save formats stay compatible.

- **Shared NPC moments and daily purpose:** nearby friends can spend a timed 20-second hangout or receive a real prepared-meal gift. Friendship tiers, memories and hangout cooldowns persist. Venue routine descriptions follow game time. Three deterministic household goals credit actual cooking, practice, NPC social time, pet care or completed transit; bounded rewards are claimable once per UTC day.

- **Saved queues and autonomy:** six waiting resident actions persist with object/place identity and validated approach paths. Clearing waiting actions keeps the current activity; cancelling stops both. Optional free-care autonomy at home honors queued choices, never works/cooks/buys/trades and stays disabled during offline catch-up.

- **Pantry, meals and learned skills:** bounded groceries repriced by current-city gas; two recipes consume ingredients at physical cooking start, produce expiring prepared meals, and unlock through cooking practice. Programming/creativity practice and three household projects grant single-use completion rewards. Pantry, meals, skills and project claims survive reload and follow NFT identity.

- **Human care:** six independently settling needs (hunger, energy, hygiene, fun, comfort and social), free physical sink washing, sofa relaxation and meaningful reading/rest benefits. Older saves receive only missing care meters and retain funds/property.

- **NFT household:** ownership follows chain/collection/token, independent of wallet. Sex/gender is editable while playing; NFT identity and original traits seed human appearance. A stable NFT seed determines human rig colors and appearance, with a matching portrait and retained painted portrait fallback. Human presentation never changes the pet's traits or household wealth.
- **Authentic source:** all 1,969 original metadata records, shuffled tokenURI mappings, 13 trait categories, hashes, frequency ranks and faucet/land proofs. Original block 115722652. Source Tier is kept separate from computed rank: original token 1 is Uncommon, even though its historical frequency rank 169 maps to Legendary.
- **Starting homes:** fresh verified Common/Uncommon/Rare/Epic/Legendary packages use one shared cash/furniture budget of 200/500/1200/2500/5000 gCHOG and source-tier land grants of 1/1/2/2/3 parcels. Layout, initial furnishings and palette are seeded by the NFT. Common homes include the essential shower; other starting furnishings remain source/seed dependent. Existing saves migrate without losing property/balances or receiving another grant.
- **Build & Buy:** household and commercial furniture types, stable object IDs, buying, positioning, moving, rotation, storage, resale, floor width/depth extensions and wall/door partitions. Overlap, bounds, funds, layout version, reachable floor and object access are validated. Owned land increases permitted floor area. Extensions add usable floor within owned land capacity.
- **Object use:** object-specific dialogs, physical approach and persisted timed paths, server-approved action start after arrival, up to six saved object intentions with reorder/remove/clear controls, free cancellation before consumption. Desks/sofas have sitting poses; beds have aligned lying poses; kitchens/bookcases use standing interactions. Neon leases exclude competing use of one object and protect building while a guest is using furniture.
- **Detailed anime presentation:** modular transparent furniture, real material tiles, cloth/window detail, constructed walls/skirting/light, painted city buildings with city palettes and separate humans/pets. Parks use benches, leafy trees and flower beds. The build catalogue uses the same furniture art as the world. Assets and prompts are in `public/art/anime`; source PNGs remain in generation artifacts.
- **Pet care:** hunger, energy, affection, bond, following/stay behavior, food cost and care cooldowns. Home feeding requires a placed bowl; parks provide communal care. Detailed reference/original-token 1 pet sprites are restored; other NFTs retain trait-based interpretations and authentic portraits.
- **Five cities:** Monhattan/Monad, Gwei York/Ethereum, Basedford/Base, Arbiquerque/Arbitrum, Polygone-on-Sea/Polygon. Each has its own infrastructure names, visual palette and enterable café, workplace, park and library layouts, with a local NPC in each. Streets retain the shared residential-grid model.
- **Camera/navigation:** homes, streets and the public world directory support bounded wheel/pinch/button zoom, drag/touch panning, explicit pan mode, arrow controls/keys and view reset. Camera gestures never issue movement or object commands. Street panning releases resident-follow; Center restores it. House/landmark labels sit above roofs on a top layer, retain screen size and stay inside the viewport while their building is visible. Directory profile buttons remain selectable after pan/zoom.
- **Travel:** walk to the station, board a 10–15-second trip, pay once, restore the trip after reload and arrive in the destination district. Home and Sanctuary recovery fares remain free. The NFT household and pet travel together; the owned home remains in its home city.
- **Relationships:** twenty city NPCs have physical conversation proximity, introduction/interests/Chog/story topics, persistent friendship, meeting counts and last memories, with cooldowns. Repeating the same topic gives a smaller friendship gain; conversation creates no money. Shared online players can wave/chat/high-five nearby outdoors.
- **Visits and property:** guests load the host's actual furniture/geometry, honor visitor access and cannot edit. Shared adjacent land purchase, escrowed offers, atomic seller payment/parcel transfer, refunds, protected root parcels and estate connectivity remain implemented in Neon.
- **Simulation/authority:** serialized reducer, continuous needs, bounded offline settlement, jobs, exact-wei gas predictions, XP/quests and NFT-bound progression. Wallet challenges/cookies, current ownership checks before writes, server time/quotes, revision conflicts and idempotent receipts. Local browser saves never enter the shared economy.
- **Contracts/faucet:** source-mapped unofficial Test Chog faucet `0x9fcC2FB7487A3530809f45DFD9bb419EA2E0aF17` and V2 registry `0xA4aB8dbc0b3213C2d80af677bD7B4b5f259BdD0f` remain deployed on Monad Testnet 10143. Lifetime wallet claim, token-zero selection, verified local source metadata and transfer-aware registration remain wired. The separately tested land contract remains undeployed.
